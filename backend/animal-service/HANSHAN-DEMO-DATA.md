# 韩山师范学院社区本地演示数据

本文件记录 CAMPUS-2A 的稳定演示 ID。所有动物、帖子和评论均为虚构内容，
只由 `local` / `dev` Profile 的 `db/demo` Flyway 路径加载；生产默认迁移不会加载。

## 关联边界

- University：`21000000-0000-4000-8000-000000001010`
- 逻辑 Campus：`22000000-0000-4000-8000-000000000001`
- 演示作者：复用 Identity 本地演示用户 `00000000-0000-0000-0000-000000000001`
- 演示审核人：复用 Identity 本地治理管理员 `00000000-0000-0000-0000-000000000002`

Animal Service 只保存跨服务 ID，不跨库创建外键或直接写 Identity 数据库。选择该高校
仅改变浏览上下文，不创建 `CampusMembership`。

位置字段仅使用“校内公共区域（虚构演示）”一类非精确描述，不包含真实楼栋、宿舍或
动物活动点。三只动物均无真实救助、领养或媒体记录。

## 待审核内容

Fixture 每次仅在记录不存在时插入，初始 `review_status` 均为 `PENDING`。
重复执行不会覆盖 `review_status`、`reviewed_by_user_id`、`reviewed_at`、内容状态、
版本或治理审计。

评论才会出现在匿名 API。

## 小程序离线演示

离线数据使用同一逻辑 Campus、Animal、Post 和 Comment ID，页面始终显示
“本地离线演示”标识。该数据不调用 Gateway，不代表数据库中内容已经通过真实审核，
也不会静默替代 API 模式失败。
